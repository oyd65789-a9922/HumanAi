설명 A 전문 용어 / 노트 기반

"알데하이드 탑 노트와 오크모스, 일랑일랑이 어우러지며, 베이스의 애니멀릭한 머스크로 마무리되는 향"

설명 B 감성적 / 추상적 묘사

"햇살이 쏟아지는 주말 아침, 새하얀 침구 위에서 뒹굴 때 느껴지는 나른하고 포근한 분위기의 향"

설명 C 경험 / 비유 기반

"햇볕에 바싹 말린 깨끗한 면 티셔츠에서 나는 뽀송뽀송한 섬유유연제 냄새"
