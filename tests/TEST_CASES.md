# SCENT LAB — 테스트 케이스 명세서 (TEST_CASES.md)

> 본 문서는 `PLAN.md` 및 `PRD`를 기준으로 SCENT LAB 익명 설문 웹앱의 기능, 보안, 분기, 통계 집계, 반응형 UI를 검증하기 위한 상세 테스트 케이스입니다.

## 2. 보안 및 서버 검증 테스트 (Security Test Cases)

| ID | 테스트 항목 | 공격/비정상 입력 시나리오 | 기대 결과 | 상태 |
|---|---|---|---|---|
| **S01** | 수식 주입(CSV/Formula Injection) 방어 | `q1`에 `=CMD("calc")` 또는 `+1234`, `@SUM(...)` 전송 | 서버 및 클라이언트 검증에서 수식 시작 특수문자 탐지 및 거절 | PASS |
| **S02** | 화이트리스트 외 임의 값 차단 | `q1`에 `hacker_value`, `q6`에 `d` 등 비표준 코드 전송 | 서버에서 `VALIDATION_FAILED` 에러 반환 및 시트 저장 차단 | PASS |
| **S03** | 배율 범위 이탈 차단 | `q4`에 `999` 또는 `-1`, `2.5` 소수점 전송 | 1~5 정수형 범위 검증 실패로 거부 | PASS |
| **S04** | 불법 분기 조작 차단 | `q2="0"`인데 `q3=4`가 포함된 비정상 페이로드 전송 | 분기 무결성 규칙 위반으로 서버에서 저장 거부 | PASS |
| **S05** | 비인가 필드(개인정보 등) 주입 차단 | 페이로드에 `email`, `ip`, `name`, `token` 등 추가 키 포함 | 허용되지 않은 키 포함으로 서버에서 즉시 거절 | PASS |
| **S06** | 동시 쓰기 경쟁 제어 (Race Condition) | 2개 이상의 요청이 동시 도달 | `LockService.tryLock(10000)`으로 데이터 덮어쓰기 없이 순차적 1행 저장 | PASS |
| **S07** | CORS 브라우저 통신 안정성 | GitHub Pages 등 타 도메인에서 `fetch` 전송 | `text/plain` 페이로드 전송으로 OPTIONS 프리플라이트 차단 회피 및 정상 JSON 응답 | PASS |
| **S08** | 스프레드시트 비공개 유지 | 브라우저 네트워크 탭 검사 | Google Sheet URL, 시트 ID, 토큰, 개별 응답자 원본 데이터 0개 노출 | PASS |
| **S09** | 에러 마스킹 (Defensive Design) | 서버 내부 오류 발생 시뮬레이션 | 시스템 내부 스택트레이스 숨김, 사용자 친화적 오류 메시지만 전달 | PASS |

## 3. UI, 접근성 및 연구 품질 테스트 (UX & Accessibility)

- [x] **모바일 반응형 대응**: 320px, 375px(iPhone), 430px(최신 모바일), 768px(태블릿), 1080px+(데스크톱) 전 해상도 가로 스크롤 없음
- [x] **터치 타깃 최소 높이**: 모바일 터치 라벨 최소 48px 이상 확보
- [x] **접근성 시맨틱**: `fieldset`, `legend`, `progressbar` (aria-valuenow), `skip-link` 적용
- [x] **연구 중립성 (Bias 배제)**: 설명 A, B, C 카드의 배경색, 폰트 크기, 패딩, 테두리가 100% 동일하며 시각적 편향 없음
- [x] **감성/전문 우열 암시 배제**: 설문 진행 중 특정 설명에 정답이나 우수성을 암시하는 문구 0개
